Concept
解憂

해우소解憂所 — 근심을 푸는 곳이라는 뜻의 옛말입니다. 길 위에서 급하게 화장실을 찾을 때, 장식 없이 가장 짧은 동선으로 가장 가까운 공중화장실을 알려주는 것이 이 프로젝트의 전부입니다.

지도 위 정보 밀도를 최소화하고, 필요한 순간 필요한 정보(거리·운영시간·접근성)만 드러나도록 설계했습니다. 화면의 30% 이상은 항상 여백으로 남겨 심리적 여유를 주는 것이 UX 원칙입니다.

Troubleshooting

API로 실습하며 실제로 부딪힌 문제들

문제 1 · 키 유출

초기 코드 번들에 GOOGLE_MAPS_API_KEY가 fallback 값으로 하드코딩된 채 공개 저장소에 커밋됐고, GitHub 시크릿 스캐닝에 즉시 감지됐습니다.

대응

기존 키를 즉시 폐기하고 .env 기반으로 전환, HTTP 리퍼러 + API 제한을 건 신규 키를 발급해 재구성했습니다.

문제 2 · 길찾기 무응답

한국 내 정밀지도 반출 규제로 Routes API의 도보/자동차 경로 계산이 항상 빈 결과를 반환한다는 사실을 실제 호출 테스트로 확인했습니다.

대응

직선거리·예상 소요시간을 추정하는 방식으로 전환하고, "실제 도보 경로 아님"을 UI에 명시해 사용자 혼란을 방지했습니다.
