(현재 앱은 Google Places API로 장소를 가져온다. 이 데이터는 이후 자체 데이터셋으로 전환할 때 쓸 원본.)

- 자치구: 26개

- 구조: `{ "DESCRIPTION": {...}, "DATA": [ {...} ] }`

### 가공할 때 주의할 점

- **`coord_x`가 경도, `coord_y`가 위도다.** 이름만 보고 `{ lat: coord_x }`로 넣으면 좌표가 뒤집힌다.
- 다중값 필드는 파이프(`|`)로 구분되고 **끝에도 파이프가 남는다** (`남자|여자|`). split 후 빈 문자열을 걸러야 한다.
- 값이 없는 칸은 `null`이 아니라 **공백 문자(`" "`)** 로 들어온다. `trim()` 후 빈 값 처리 필요.
- `value_02`(개방시간)는 `상시(24시간)` 외에 자유 서술이 섞여 있어, 24시간 여부를 판별하려면 문자열 매칭 규칙이 필요하다.
